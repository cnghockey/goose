This tutorial covers how to add the [Sats4AI MCP Server](https://github.com/cnghockey/sats4ai-mcp-server) as a goose extension to give goose access to 33+ paid AI services — image generation, video, text-to-speech, transcription, translation, OCR, file conversion, SMS, email, and phone calls. Each request is paid with a Bitcoin Lightning micropayment. No API keys, no accounts, no sign-up.

## How Payments Work

Sats4AI prices every service in satoshis (1 sat = 1/100,000,000 BTC). A typical flow:

1. goose calls a tool, for example `translate_text`
2. The server responds with a Lightning invoice and a `payment_id`
3. You pay the invoice from any Lightning wallet (most tools cost 1–200 sats, a fraction of a cent to a few cents)
4. goose retries the call with the `payment_id` and receives the result

If a service fails after payment, the server returns an LNURL-withdraw refund link automatically.

Live tool catalog with current pricing: [sats4ai.com/api/mcp/discovery](https://sats4ai.com/api/mcp/discovery)

## Available Tools

- **Image**: generation, editing, background removal, upscaling, face restoration
- **Video**: text-to-video, image animation, subtitles
- **Audio**: text-to-speech (600+ languages), transcription, voice cloning
- **Text**: translation (119+ languages), chat models, document Q&A
- **Documents**: OCR, receipt extraction, PDF/file conversion, EPUB-to-audiobook
